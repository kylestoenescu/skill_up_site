REST APIs

Overview

REST (Representational State Transfer) is an architectural style for designing web APIs around resources — things like users, orders, or documents — each identified by its own URL.

Clients interact with resources using standard HTTP methods: GET to read, POST to create, PUT/PATCH to update, and DELETE to remove. Responses use HTTP status codes to signal the outcome, such as 200 OK, 201 Created, or 404 Not Found.

A key principle of REST is that it's stateless — each request must carry everything the server needs to process it, since the server doesn't retain session state between requests. Payloads are most commonly formatted as JSON.
