FHIR

Overview

FHIR (Fast Healthcare Interoperability Resources) is a standard, maintained by HL7, for exchanging healthcare data between systems — think electronic health records, lab systems, and insurance platforms.

Data is organized into Resources: modular units like Patient, Observation, Encounter, and Condition, each with a defined structure. Resources can be represented as JSON or XML.

FHIR exposes these resources through a RESTful API, so common HTTP verbs (GET, POST, PUT) work the way they do in any other REST API — for example, GET /Patient/123 retrieves a specific patient record.
