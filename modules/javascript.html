JavaScript

Overview

JavaScript is the scripting language that runs in every web browser, making pages interactive. It also runs outside the browser via runtimes like Node.js, powering servers, tooling, and scripts.

JavaScript is dynamically typed and event-driven. Variables are declared with let, const, or the older var, and the language relies heavily on functions — including closures, callbacks, and arrow functions — to structure code.

Modern JavaScript handles asynchronous work with Promise objects and the async/await syntax, letting code wait for things like network requests without blocking the rest of the page.
