SOAP

Overview

SOAP (Simple Object Access Protocol) is an XML-based messaging protocol for exchanging structured information between systems. It's older than REST and still widely used in enterprise, financial, and healthcare integrations.

Every SOAP message is wrapped in an Envelope, which contains an optional Header (metadata like authentication) and a required Body (the actual request or response). If something goes wrong, the response includes a Fault element describing the error.

A SOAP service publishes a WSDL (Web Services Description Language) file, which defines exactly what operations are available and what data they expect — giving SOAP a strict, machine-readable contract that REST doesn't enforce by default.
