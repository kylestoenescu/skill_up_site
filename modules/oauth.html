OAuth

Overview

OAuth 2.0 is an authorization framework that lets one application access a user's data on another service without ever seeing that user's password. It's how "Sign in with Google" or "Connect your Calendar" flows work.

OAuth defines four roles: the resource owner (the user), the client (the app requesting access), the authorization server (issues tokens), and the resource server (hosts the protected data).

After the user approves access, the client receives an access token — a credential it presents on each request instead of a password. Requests can also be scoped, so the client only gets the specific permissions (scopes) it asked for.
