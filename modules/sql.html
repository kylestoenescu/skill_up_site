SQL

Overview

SQL (Structured Query Language) is how you talk to relational databases. It lets you read and modify data with statements like SELECT, INSERT, UPDATE, and DELETE.

Data lives in tables made of rows and columns. You filter rows with WHERE, combine related tables with JOIN, and summarize data with GROUP BY alongside aggregate functions like COUNT() or SUM().

Tables typically define a primary key that uniquely identifies each row, and other tables reference it via a foreign key to model relationships between data.
